# Additional Java Projects

- Algorithmic exercises and proofs of concept (e.g., search algorithms, simple GUI utilities)  
- Enhanced versions of older projects, better implementation (lesser lines of code), showcasing improved structure and readability

## Technologies & Tools
- Java (JDK)  
- IDE: VS Code or IntelliJ IDEA  
- Standard libraries (java.util, java.io)  
- Git & GitHub for code versioning and iteration
